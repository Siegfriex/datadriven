## Executive Summary

ARGO 프로젝트는 **한국 미술계의 숨겨진 구조와 권력 관계를 데이터드리븐 시각화로 드러내는 분석 플랫폼**을 목표로 합니다. 

**핵심 가치 제안:**
- **구조주의 관점**: 개인을 뛰어넘는 제도·학술·담론·네트워크 레이어 분석
- **4-Capital Model**: Institutional, Academic, Media, Network 자본 측정
- **3D 갤럭시 모델**: 한국 미술계를 입자 시스템으로 시각화
- **패턴 탐지**: 보이지 않는 제도, 권력 구조, 이상치 자동 식별

**현재 마일스톤 달성도**: **60%** (데이터 수집 및 제도/학술 레이어 강화 완료)

### 1.2 4-Capital Model 점수 계산 현황

#### A. Institutional Capital (제도 자본) ✅ **강함**

**목표 지표:**
- Museum exhibitions (MMCA, KMOCA, municipal museums)
- Biennale/triennial participation
- Public funding (ARKO, Seoul Foundation)
- Artist residency programs

**현재 구현 상태:**
- ✅ 작품 수: ARKO 미술작품 정보 (24,762개)
- ✅ 비엔날레 참여: 청주공예비엔날레 API (참여 횟수 + 입상 정보)
- ✅ 레지던시 참여: MMCA 레지던시작가소식 API (참여 횟수)
- ✅ 소장작품: MMCA 소장작품 API (소장작품 수)
- ⚠️ 전시 횟수: MMCA 크롤링 예정 (미완료)
- ⚠️ 공공 지원금: ARKO 채용정보만 활용 (제한적)

**달성도**: **85%** ✅

**계산식 구현:**
```python
inst_score = (museum_count * 20) + (biennale_count * 30) + 
             (support_count * 10) + (residency_count * 10)
```

**강점:**
- 국립현대미술관 소장작품 정보로 제도적 인정의 최고 지표 확보
- 비엔날레 참여 정보로 국제적 제도 인정 측정 가능
- 레지던시 참여 정보로 제도적 지원 측정 가능

**약점:**
- 전시 횟수 데이터 미수집 (MMCA 크롤링 필요)
- 공공 지원금 정보 제한적 (ARKO 채용정보만 활용)

---

#### B. Academic Capital (학술 자본) ✅ **강함**

**목표 지표:**
- KCI (Korea Citation Index) citations
- Exhibition catalog mentions
- Academic publications about the artist
- Art history textbook inclusions

**현재 구현 상태:**
- ✅ 논문 수: KCI 논문 정보 API (~10,000개 미술 관련 논문)
- ✅ 실제 인용 수: KCI 인용 정보 API (~1,400,000명 저자 인용 정보)
- ✅ H지수: KCI 인용 정보 API에서 제공
- ✅ 평균 인용 수: KCI 인용 정보 API에서 제공
- ✅ 자기 인용 수: KCI 인용 정보 API에서 제공
- ❌ 카탈로그 언급: 미수집
- ❌ 교과서 포함: 미수집

**달성도**: **75%** ✅

**계산식 구현:**
```python
acad_score = (citation_count * 2) + (catalog_count * 5) + 
             (academic_publications * 3)
```

**강점:**
- 실제 인용 수로 학술 영향력 정확도 대폭 향상
- H지수, 평균 인용 수 등 추가 지표 제공
- 자기 인용 분석으로 연구 독립성 측정 가능

**약점:**
- 카탈로그 언급 정보 미수집 (전시 카탈로그 크롤링 필요)
- 교과서 포함 정보 미수집 (미술사 교과서 분석 필요)

---

#### C. Media Capital (담론/미디어 자본) ❌ **약함**

**목표 지표:**
- Newspaper articles (quality-weighted)
- Magazine features
- Social media engagement
- Online platform presence

**현재 구현 상태:**
- ❌ 언론 기사 수: 미수집
- ❌ 감정 분석: 미구현
- ❌ 소셜 미디어 참여: 미수집
- ❌ 온라인 플랫폼 존재: 미수집

**달성도**: **0%** ❌

**계산식 구현 (현재):**
```python
media_score = (article_count * 1) + (sentiment_score * 20)
# 현재는 article_count와 sentiment_score가 모두 0
```

**위험 요인:**
- 담론 레이어 점수가 모두 0으로 계산됨
- 복합 점수 계산 시 담론 레이어 기여도 없음 (가중치 25% 손실)
- 작가의 공적 가시성 측정 불가능

**필요 작업:**
1. 언론 기사 크롤링 (네이버 뉴스, 다음 뉴스, 주요 일간지)
2. 감정 분석 모델 구축 (긍정/부정/중립)
3. 소셜 미디어 API 연동 (Instagram, Facebook 등)
4. 온라인 플랫폼 크롤링 (갤러리 웹사이트, 아트플랫폼)

---

#### D. Network Capital (네트워크 자본) ⚠️ **부분적**

**목표 지표:**
- Co-exhibition frequencies
- Institutional affiliations
- Mentorship relationships
- Gallery representation networks

**현재 구현 상태:**
- ✅ 협력자 수: 작가-작가 관계 데이터 수집 (공동저자, 공동작품)
- ✅ 기관 소속: 작가-기관 관계 데이터 수집 (AFFILIATED_WITH)
- ⚠️ 중심성 계산: 관계 데이터는 있지만 중심성 계산 미완
- ❌ 멘토십 관계: 미수집
- ❌ 갤러리 대표 네트워크: 미수집

**달성도**: **50%** ⚠️

**계산식 구현 (현재):**
```python
network_score = (collaborators * 5) + (centrality * 40)
# 현재는 centrality가 0으로 계산됨
```

**위험 요인:**
- 네트워크 중심성 계산 미완 (degree, betweenness, eigenvector centrality)
- 네트워크 레이어 점수가 협력자 수에만 의존
- 복합 점수 계산 시 네트워크 레이어 기여도 제한적 (가중치 25% 손실)

**필요 작업:**
1. Neo4j 그래프 분석 쿼리 구현 (중심성 계산)
2. 공동 전시 빈도 분석 (작가-작가 관계 강화)
3. 멘토십 관계 수집 (대학 교수-학생 관계 등)
4. 갤러리 대표 네트워크 수집 (갤러리-작가 관계)

## 2. 미식별 위험 요인 (Unidentified Risk Factors)

### 2.1 데이터 품질 위험

#### A. 이름 매칭 정확도 문제 ⚠️ **중요**

**위험:**
- 동명이인 문제로 인한 잘못된 매칭 가능성
- 작가 이름의 한글/영문 표기 불일치
- 작가 이름 변경 (결혼, 개명 등)

**영향:**
- 작가의 학술 점수가 부정확해질 수 있음
- 작가의 제도 점수가 부정확해질 수 있음
- 네트워크 관계가 잘못 매핑될 수 있음

**현재 완화 방안:**
- 발행기관 정보 추가 확인
- 논문 주제분야와 작가 장르 일치도 검증
- 이름 기반 매칭 (정확 일치 우선, 부분 일치 보조)

**미식별 위험:**
- **작가 ID 기반 매칭으로 전환 필요** (현재는 이름 기반)
- **작가 이름 정규화 로직 강화 필요** (한글/영문 표기 통일)
- **작가 이름 변경 이력 추적 필요** (별명, 예명 등)

---

#### B. 데이터 신뢰도 불균형 ⚠️ **중요**

**위험:**
- ARKO 데이터: 신뢰도 0.95 (공식 데이터)
- KCI 데이터: 신뢰도 0.85-0.90 (학술 데이터)
- 웹 크롤링 데이터: 신뢰도 0.70 (낮음)
- 담론 레이어 데이터: 신뢰도 0 (미수집)

**영향:**
- 제도/학술 레이어는 높은 신뢰도, 담론/네트워크 레이어는 낮은 신뢰도
- 복합 점수 계산 시 신뢰도 불균형으로 인한 편향 가능성

**미식별 위험:**
- **신뢰도 가중치 조정 필요** (낮은 신뢰도 데이터의 영향력 감소)
- **담론 레이어 데이터 수집 시 신뢰도 검증 필요** (출처 확인)

---

#### C. 데이터 업데이트 주기 불일치 ⚠️ **중요**

**위험:**
- ARKO 작가 목록: 2020년 5월 데이터 (5년 전)
- KCI 논문 정보: 연간 업데이트
- MMCA 소장작품: 비정기 업데이트
- 담론 레이어: 실시간 업데이트 필요

**영향:**
- 작가 정보가 오래되어 현재 상태와 불일치 가능성
- 시계열 분석 시 데이터 불일치로 인한 오류 가능성

**미식별 위험:**
- **데이터 업데이트 주기 모니터링 필요** (각 API의 업데이트 주기 추적)
- **데이터 시점 메타데이터 추가 필요** (각 데이터의 수집 시점 기록)
- **오래된 데이터 필터링 옵션 제공 필요** (사용자가 데이터 시점 선택 가능)

---

### 2.2 점수 계산 위험

#### A. 담론 레이어 점수 0 문제 ❌ **Critical**

**위험:**
- 담론 레이어 점수가 모두 0으로 계산됨
- 복합 점수 계산 시 담론 레이어 기여도 없음 (가중치 25% 손실)

**영향:**
- 작가의 공적 가시성 측정 불가능
- 복합 점수 계산 정확도 저하
- 작가 비교 분석 시 담론 레이어 제외

**미식별 위험:**
- **담론 레이어 데이터 수집이 시급함** (언론 기사 크롤링 우선순위 상향)
- **임시 가중치 조정 고려** (담론 레이어 0일 경우 다른 레이어 가중치 증가)

---

#### B. 네트워크 중심성 계산 미완 ⚠️ **중요**

**위험:**
- 네트워크 중심성 계산 미완 (degree, betweenness, eigenvector centrality)
- 네트워크 레이어 점수가 협력자 수에만 의존

**영향:**
- 네트워크 레이어 점수 정확도 저하
- 복합 점수 계산 시 네트워크 레이어 기여도 제한적

**미식별 위험:**
- **Neo4j 그래프 분석 쿼리 구현 필요** (중심성 계산 우선순위 상향)
- **네트워크 분석 알고리즘 라이브러리 도입 고려** (NetworkX, igraph 등)

---

#### C. 가중치 검증 부족 ⚠️ **중요**

**위험:**
- 4-Capital Model 가중치 (0.30, 0.20, 0.25, 0.25)가 메타분석 기반이지만 실제 데이터로 검증되지 않음
- 한국 미술계 특성에 맞는 가중치 조정 필요 가능성

**영향:**
- 복합 점수 계산 정확도 불확실성
- 작가 비교 분석 시 가중치 편향 가능성

**미식별 위험:**
- **가중치 검증 연구 필요** (실제 작가 데이터로 가중치 검증)
- **가중치 조정 메커니즘 구축 필요** (사용자 정의 가중치 옵션 제공)

---

### 2.3 네트워크 분석 위험

#### A. 관계 데이터 불완전 ⚠️ **중요**

**위험:**
- 작가-작가 관계: 공동저자, 공동작품만 수집 (공동 전시 미수집)
- 작가-기관 관계: 소속 정보만 수집 (멘토십, 갤러리 대표 미수집)
- 작가-전시 관계: 미수집

**영향:**
- 네트워크 분석 정확도 저하
- 커뮤니티 탐지 정확도 저하

**미식별 위험:**
- **공동 전시 정보 수집 필요** (전시 카탈로그 크롤링)
- **멘토십 관계 수집 필요** (대학 교수-학생 관계 등)
- **갤러리 대표 네트워크 수집 필요** (갤러리-작가 관계)

---

#### B. 그래프 분석 알고리즘 미구현 ❌ **Critical**

**위험:**
- 중심성 분석 미구현 (degree, betweenness, eigenvector centrality)
- 커뮤니티 탐지 미구현 (Louvain 알고리즘)
- 이상치 탐지 미구현 (통계적 이상치)

**영향:**
- 네트워크 분석 기능 미사용 가능
- 구조 분석 기능 제한적

**미식별 위험:**
- **그래프 분석 알고리즘 구현 필요** (Neo4j GDS 라이브러리 활용)
- **커뮤니티 탐지 알고리즘 구현 필요** (Louvain 알고리즘)
- **이상치 탐지 알고리즘 구현 필요** (통계적 이상치 탐지)

## 3. 미식별 기회 요인 (Unidentified Opportunity Factors)

### 3.1 데이터 통합 기회

#### A. 다중 소스 데이터 융합 ✅ **높은 잠재력**

**기회:**
- 9개 API에서 수집한 데이터를 통합하여 작가 프로필 강화
- 제도 레이어: 작품 + 비엔날레 + 레지던시 + 소장작품 통합
- 학술 레이어: 논문 + 인용 정보 통합

**영향:**
- 작가 프로필 정확도 대폭 향상
- 점수 계산 정확도 향상

**활용 방안:**
- **작가 프로필 통합 대시보드 구축** (모든 데이터 소스 통합 표시)
- **데이터 소스 신뢰도 가중치 적용** (높은 신뢰도 데이터 우선)

---

#### B. 시계열 분석 기회 ✅ **높은 잠재력**

**기회:**
- 논문 발행년 정보로 작가의 학술 활동 생애주기 파악
- 작품 제작연도 정보로 작가의 작품 활동 생애주기 파악
- 비엔날레 참여 연도 정보로 작가의 제도적 인정 변화 추이 파악

**영향:**
- 작가의 경력 단계 분석 가능
- 작가의 활동 패턴 분석 가능

**활용 방안:**
- **시계열 분석 기능 구축** (연도별 점수 변화 추이 시각화)
- **작가 경력 단계 분류** (신진/중견/원로 작가 분류)

---

#### C. 네트워크 분석 기회 ✅ **높은 잠재력**

**기회:**
- 공동저자 관계로 작가 간 학술 협력 네트워크 구축
- 공동작품 관계로 작가 간 작품 협력 네트워크 구축
- 기관 소속 관계로 작가-기관 네트워크 구축

**영향:**
- 보이지 않던 작가 간 네트워크 구조 발견 가능
- 작가의 네트워크 위치 파악 가능

**활용 방안:**
- **네트워크 시각화 기능 구축** (작가 간 관계 그래프 시각화)
- **네트워크 중심성 분석 기능 구축** (중심성 지표 시각화)
- **커뮤니티 탐지 기능 구축** (작가 그룹 자동 분류)

---

### 3.2 인사이트 발견 기회

#### A. 작가-연구자 이중 정체성 발견 ✅ **높은 잠재력**

**기회:**
- 작가 중 상당수가 연구자이기도 함 (대학 교수, 연구자 등)
- 작가의 학술적 정전화가 작품 가치에 미치는 영향 분석 가능

**영향:**
- 작가의 이중 정체성 분석 가능
- 학술적 정전화와 작품 가치의 상관관계 분석 가능

**활용 방안:**
- **작가-연구자 이중 정체성 분류** (작가/연구자/이중 정체성 분류)
- **학술적 정전화와 작품 가치 상관관계 분석** (논문 수와 작품 가치 상관관계)

---

#### B. 제도적 인정의 계층 구조 발견 ✅ **높은 잠재력**

**기회:**
- 국립현대미술관 소장작품 수는 제도적 인정의 최고 지표
- 비엔날레 참여는 제도적 인정의 중간 지표
- 레지던시 참여는 제도적 지원의 지표

**영향:**
- 제도적 인정의 계층 구조 파악 가능
- 작가의 제도적 위치 정확도 향상

**활용 방안:**
- **제도적 인정 계층 구조 시각화** (소장작품 > 비엔날레 > 레지던시 계층 구조)
- **작가의 제도적 위치 분류** (최고/중간/기본 제도적 인정 분류)

---

#### C. 학술 영향력과 제도적 인정의 상관관계 발견 ✅ **높은 잠재력**

**기회:**
- 논문 수와 소장작품 수의 상관관계 분석 가능
- 인용 수와 비엔날레 참여의 상관관계 분석 가능

**영향:**
- 학술적 영향력과 제도적 인정의 상관관계 파악 가능
- 작가의 성공 요인 분석 가능

**활용 방안:**
- **학술-제도 상관관계 분석 기능 구축** (논문 수와 소장작품 수 상관관계 시각화)
- **작가 성공 요인 분석 기능 구축** (학술/제도/담론/네트워크 중 성공 요인 분석)

---

### 3.3 기술적 기회

#### A. LLM 기반 인사이트 생성 ✅ **높은 잠재력**

**기회:**

**활용 방안:**

- **이상치 탐지 및 가설 생성 기능 구축** (통계적 이상치 자동 탐지 및 가설 생성)

---
