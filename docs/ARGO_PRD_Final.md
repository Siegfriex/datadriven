# ARGO: 한국 미술계 구조 분석 엔진
## Product Requirements Document (PRD)

**Version**: 1.0  
**Last Updated**: 2025-12-08  
**Status**: Ready for Development  
**Author**: Project ARGO Team

---

## Executive Summary

**ARGO**는 한국 미술계의 숨겨진 구조와 권력 관계를 **데이터드리븐 시각화**로 드러내는 분석 플랫폼이다. 

**핵심 가치:**
- **구조주의 관점**: 개인을 뛰어넘는 제도·학술·담론·네트워크 레이어 분석
- **3D 갤럭시 모델**: 한국 미술계를 입자 시스템으로 시각화
- **패턴 탐지**: 보이지 않는 제도, 권력 구조, 이상치 자동 식별
- **데이터 기반 가설**: LLM + 통계 검증으로 학문적 엄밀성 확보

### 3.3 갤럭시 시각화 (Main Canvas)

#### 3.3.1 입자 시스템 (Particle System)

**각 작가 = 구 (Sphere)**

```
색상: RGB 맵핑
  R = 제도 점수 (0-255)
  G = 학술 점수 (0-255)
  B = 담론 점수 (0-255)

크기 (반경): 네트워크 점수 기반
  radius = 10 + (network_score / 5)
  
위치 (3D 좌표):
  x축 = 제도 점수 정규화 (-10 ~ 10)
  y축 = 학술 점수 정규화 (-10 ~ 10)
  z축 = 담론 점수 정규화 (-10 ~ 10)

광도 (Emissive):
  emissiveIntensity = composite_score / 100 * 0.5
  (높은 점수 = 더 밝게)

마우스 오버:
  • 반경 1.5배 확대
  • 이름 툴팁 표시
  • 협력자 관계선 표시 (흰색 선, 강도 기반)

클릭:
  • 우측 패널에서 상세 정보 표시
  • 신호음 피드백
  • 주변 1홉 협력자 강조 표시
```

#### 3.3.2 군집 표현 (Cluster Representation)

**각 군집 = 투명한 구 + 라벨**

```
구 (Sphere):
  center = 군집 중심 좌표
  radius = 군집 반경
  color = 고정 색상 (군집별)
  opacity = 0.1 (투명)
  wireframe = true (와이어프레임)
  
라벨:
  텍스트 = 군집 이름
    예) "Seoul Academia & Monochrome"
        "Busan Gallery Network"
        "International Contemporary"
  
  위치 = 군집 중심 위, 약간 떨어진 곳
  크기 = 군집 규모에 따라 조정
  색상 = 군집 색상과 동일

마우스 오버:
  • 군집 경계선 강조
  • 구성 작가 수 표시
  • 평균 점수 표시

클릭:
  • 군집 내 모든 작가 강조
  • 군집 상세 정보 우측 패널에 표시
  • 카메라 줌 인 (군집을 화면 중심으로)
```

### 7.2 점수 계산 로직 - 구조주의 기반 (v1.0_structuralist)

```
이론적 기초:
  - Pierre Bourdieu 장(Field) 이론 (1984, 1993)
  - 4개 자본 유형: 제도적, 문화적, 상징적, 사회적 자본
  - 메타 분석 기반 가중치 도출 (8개 선행 연구)

가중치 학술적 근거:
  - 제도 (0.30): Fraiberger et al. (2018) Science, r=0.68
  - 학술 (0.20): Galenson (2006), Lang & Lang (1988), r=0.60
  - 담론 (0.25): Artnet (2019), Thompson (2008), r=0.57
  - 네트워크 (0.25): Granovetter (1973), Fraiberger (2018), r=0.58
```

```python
# 제도 레이어 (Institutional Capital)
def calculate_inst_score(artist):
    """
    Bourdieu의 상징적 자본 중 제도적 인정
    근거: Fraiberger et al. (2018) - 초기 기관 위상 → 장기 성공
    """
    INSTITUTION_PRESTIGE = {
        'national_museum': 100,   # 국립현대미술관
        'major_biennale': 95,     # 베니스, 광주 비엔날레
        'municipal_museum': 80,   # 서울시립미술관 등
        'university_museum': 70,  # 대학 미술관
    }
    EXHIBITION_TYPE_WEIGHT = {
        'solo': 1.5, 'biennale': 1.8, 'retrospective': 2.0, 'group': 1.0
    }
    raw_score = sum(
        INSTITUTION_PRESTIGE.get(e.inst_type, 30) *
        EXHIBITION_TYPE_WEIGHT.get(e.exh_type, 1.0) *
        max(0.5, 1 - (years_ago * 0.03))  # 시간 감쇠
        for e in artist.exhibitions
    )
    return normalize(raw_score, 0, 100)

# 학술 레이어 (Cultural/Academic Capital)
def calculate_acad_score(artist):
    """
    Bourdieu의 문화적 자본 중 학술적 정전화
    근거: Galenson (2006) - 교과서 인용 ↔ 장기 가치 r=0.71
    """
    PUBLICATION_WEIGHT = {
        'art_history_textbook': 30,  # 미술사 교과서
        'monograph': 25,             # 단독 연구서
        'exhibition_catalog': 15,    # 전시 카탈로그
        'journal_article': 10        # 학술지 논문
    }
    raw = sum(PUBLICATION_WEIGHT.get(p.type, 3) for p in artist.publications)
    raw += min(50, artist.citation_count * 2)  # 인용 (최대 50)
    return normalize(raw, 0, 100)

# 담론 레이어 (Media/Symbolic Capital)
def calculate_media_score(artist):
    """
    미디어 가시성 + 감정 분석
    근거: Thompson (2008), Artnet (2019)
    """
    MEDIA_WEIGHT = {'major_newspaper': 10, 'art_magazine': 8, 'broadcast': 12}
    raw = sum(MEDIA_WEIGHT.get(a.type, 2) * time_decay(a.year) for a in artist.media)
    sentiment = avg([a.sentiment for a in artist.media])  # -1 ~ 1
    hype_ratio = raw / (artist.inst_score + 1)  # 과대포장 지수
    return normalize(raw, 0, 100), sentiment, hype_ratio

# 네트워크 레이어 (Social Capital)
def calculate_network_score(artist, graph):
    """
    사회적 자본 = 협력 네트워크
    근거: Granovetter (1973), Fraiberger et al. (2018)
    """
    return (
        degree_centrality(graph, artist) * 30 +
        betweenness_centrality(graph, artist) * 35 +  # 가장 예측력 높음
        eigenvector_centrality(graph, artist) * 25 +
        bridge_potential(graph, artist) * 10
    )

# 복합 점수 (Composite Score)
def calculate_composite_score(artist, inst, acad, media, network):
    """
    구조주의적 종합: 자본의 총량 + 구성 분석
    """
    BASE_WEIGHTS = {'inst': 0.30, 'acad': 0.20, 'media': 0.25, 'network': 0.25}

    # 세그먼트별 조정 (장르 특성 반영)
    SEGMENT_ADJUSTMENTS = {
        'monochrome': {'inst': 1.17, 'acad': 1.25, 'media': 0.80, 'network': 0.80},
        'media_art': {'inst': 0.83, 'acad': 0.75, 'media': 1.20, 'network': 1.20},
        'emerging': {'inst': 0.83, 'acad': 0.75, 'media': 1.20, 'network': 1.20}
    }

    adj = SEGMENT_ADJUSTMENTS.get(artist.segment, {'inst': 1, 'acad': 1, 'media': 1, 'network': 1})
    composite = (
        inst * BASE_WEIGHTS['inst'] * adj['inst'] +
        acad * BASE_WEIGHTS['acad'] * adj['acad'] +
        media * BASE_WEIGHTS['media'] * adj['media'] +
        network * BASE_WEIGHTS['network'] * adj['network']
    )

    # 지배적 자본 분석 (구조주의적 해석)
    scores = {'inst': inst, 'acad': acad, 'media': media, 'network': network}
    dominant_capital = max(scores, key=scores.get)

    return {
        'composite': composite,
        'dominant_capital': dominant_capital,
        'capital_composition': {k: v/sum(scores.values()) for k, v in scores.items()},
        'methodology_version': 'v1.0_structuralist'
    }
```

## 부록 D. 가중치 학술적 근거 (v1.0_structuralist)

### D.1 이론적 기초: Bourdieu 장(Field) 이론

```
핵심 원칙:
1. 관계의 우선성: 개인 속성보다 "관계 구조" 속 위치가 중요
2. 전체성: 부분(개별 미술가)은 전체(미술계 구조) 안에서만 의미
3. 자본 총량 + 자본 구성: 장 내 위치를 결정하는 두 축

4개 자본 유형 → ARGO 4개 레이어:
├─ 제도적 자본 (Institutional Capital) → inst_score
├─ 문화적 자본 (Cultural Capital) → acad_score
├─ 상징적 자본 (Symbolic Capital) → media_score
└─ 사회적 자본 (Social Capital) → network_score
```

```
한계점:

   └─ 영향: 통계적 유의성 제한, 일반화 어려움

   └─ 현재: 한국 미술계에 특화된 가중치
   └─ 영향: 다른 국가 미술계 적용 시 조정 필요
   └─ 완화: 국제 비교 연구로 일반화 가능성 검증

3. 시간에 따른 가중치 변화 가능성
   └─ 현재: 고정 가중치 (0.30, 0.20, 0.25, 0.25)
   └─ 영향: 미술계 구조 변화 시 가중치 재조정 필요
   └─ 완화: 시계열 분석으로 가중치 변화 추적
```
