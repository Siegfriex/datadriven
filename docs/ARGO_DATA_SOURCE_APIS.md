## 문서 개요

이 문서는 ARGO 프로젝트에서 사용하는 **외부 데이터 소스 API**를 관리합니다.

**참조 문서:**
- `ARGO_API_SPECIFICATION.yaml`: ARGO 백엔드 API 명세서 (프론트엔드-백엔드 간 API)
- `ARGO_DATA_COLLECTION_METHODOLOGY.md`: 데이터 수집 방법론 및 파이프라인 상세

**구분:**
- **데이터 소스 API** (이 문서): 외부에서 데이터를 수집하는 API
- **백엔드 API** (`ARGO_API_SPECIFICATION.yaml`): ARGO 시스템이 제공하는 API

- **인용 수 추정**: KCI 등재 논문 수를 임시로 `citation_count`로 활용 (향후 실제 인용 수로 대체)
- **학술 점수 계산식 업데이트**: `(citation_count * 2) + (catalog_count * 5) + (academic_publications * 3)`
- **작가-연구자 네트워크**: 공동저자 정보를 활용하여 작가 간 학술 협력 관계 발견 가능
- **주제분야 분석**: 논문 주제분야와 작가 장르 간 상관관계 분석 가능
- **시계열 분석**: 발행년 정보를 활용하여 작가의 학술 활동 기간 및 트렌드 분석 가능

- 논문 인용: KCI API 연동 완료 ✅
  - KCI 등재 논문 수를 `academic_publications` 필드에 반영

  - **KCI 인용 정보 API로 실제 인용 수 반영** ✅

- 언론 기사 수: 웹 크롤링 예정
- 감정 분석: 별도 처리 필요

**네트워크 점수 (network_score) 계산:**

## 7. KCI API 인사이트 분석

### 7.1 기존 데이터와의 조합 분석

#### A. 작가 데이터와의 조합
- **작가-논문 매칭**: 작가 이름으로 KCI 논문 저자 매칭
- **학술 활동 측정**: 작가의 학술 연구 활동량 정량화
- **연구자-작가 이중 정체성**: 작가이면서 연구자인 인물 식별 가능

#### B. 작품 데이터와의 조합
- **작품-논문 주제 연계**: 논문 키워드와 작품 장르 간 상관관계 분석
- **이론-실천 연결**: 작가의 이론적 연구와 작품 실천 간 관계 파악

#### C. 기관 데이터와의 조합
- **대학-작가 관계**: 발행기관 정보로 작가-대학 관계 매핑
- **연구기관 네트워크**: 공동저자 정보로 연구 협력 네트워크 구축

### 7.2 기회 요인

#### A. 학술 점수 계산 정확도 향상
- **기회**: KCI 논문 수를 학술 점수에 직접 반영하여 정확도 향상
- **영향**: 작가의 학술적 정전화 정도를 더 정확히 측정 가능
- **활용**: `academic_publications` 필드로 논문 수 집계, 학술 점수 계산식에 반영

#### B. 작가-연구자 네트워크 발견
- **기회**: 공동저자 정보를 활용하여 작가 간 학술 협력 관계 발견
- **영향**: 보이지 않던 작가 간 학술 네트워크 구조 발견 가능
- **활용**: 공동저자 관계를 `COLLABORATED_WITH` 관계로 Neo4j에 저장

#### C. 주제분야-작가 장르 상관관계 분석
- **기회**: 논문 주제분야와 작가 장르 간 상관관계 분석
- **영향**: 작가의 이론적 관심사와 작품 장르 간 일치도 측정 가능
- **활용**: 주제분야 분포 분석으로 작가의 학술적 관심사 파악

#### D. 시계열 학술 활동 분석
- **기회**: 발행년 정보를 활용하여 작가의 학술 활동 기간 및 트렌드 분석
- **영향**: 작가의 학술 활동 생애주기 파악 가능
- **활용**: 연도별 논문 발행 추이로 작가의 학술 활동 패턴 분석

#### E. 실제 인용 수 확인 (KCI 인용 정보 API)
- **기회**: 기존 추정 인용 수를 실제 인용 수로 대체
- **영향**: 학술 점수 계산 정확도 대폭 향상
- **활용**: `citation_count` 필드에 실제 인용 수 반영, H지수 제공

#### F. 비엔날레 참여 정보 수집 (청주공예비엔날레 API)
- **기회**: 작가의 비엔날레 참여 정보를 정량화
- **영향**: 제도 점수 계산 정확도 향상
- **활용**: `biennale_participation` 필드에 참여 횟수 반영, 입상 정보 수집

#### G. 레지던시 참여 정보 수집 (MMCA 레지던시작가소식 API)
- **기회**: 작가의 레지던시 참여 정보를 정량화
- **영향**: 제도 점수 계산 정확도 향상
- **활용**: `residency_count` 필드에 참여 횟수 반영, 제도적 지원 측정

#### H. 소장작품 정보 수집 (MMCA 소장작품 API)
- **기회**: 작가의 국립현대미술관 소장작품 정보를 정량화
- **영향**: 제도 점수 계산 정확도 대폭 향상
- **활용**: `mmca_collection_count` 필드에 소장작품 수 반영, 제도적 인정의 최고 지표로 활용

### 7.3 위험 요인

#### A. 이름 매칭 정확도 문제
- **위험**: 동명이인 문제로 인한 잘못된 매칭 가능성
- **영향**: 작가의 학술 점수가 부정확해질 수 있음
- **완화 방안**: 
  - 발행기관 정보 추가 확인
  - 논문 주제분야와 작가 장르 일치도 검증
  - 향후 작가 ID 기반 매칭으로 전환

#### B. 미술 관련 필터링의 한계
- **위험**: 키워드 기반 필터링으로 인한 누락 또는 과도한 포함 가능성
- **영향**: 미술과 무관한 논문 포함 또는 미술 관련 논문 누락 가능
- **완화 방안**: 
  - 필터링 키워드 지속적 개선
  - 주제분야 필드 활용 강화
  - 수동 검증 샘플링

#### C. 인용 수 추정의 한계 (해결됨 ✅)
- **위험**: KCI 등재 논문 수를 인용 수로 간주하는 것은 부정확함
- **영향**: 실제 인용 수와 차이가 날 수 있음
- **완화 방안**: 
  - **KCI 인용 정보 API 연동 완료** ✅
  - 실제 인용 수를 `citation_count` 필드에 반영
  - H지수, 평균 인용 수 등 추가 지표 제공

### 7.4 숨겨진 인사이트

#### A. 작가-연구자 이중 정체성 발견
- **인사이트**: 작가 중 상당수가 연구자이기도 함 (대학 교수, 연구자 등)
- **의미**: 작가의 학술적 정전화가 작품 가치에 미치는 영향 분석 가능
- **활용**: 작가의 이중 정체성을 `jobTitle` 필드에 반영

#### B. 학술 네트워크와 작품 네트워크의 분리
- **인사이트**: 작가 간 학술 협력 네트워크와 작품 협력 네트워크가 다를 수 있음
- **의미**: 학술적 권위와 작품적 권위가 별개의 구조임을 시사
- **활용**: 네트워크 레이어 분석 시 학술 네트워크와 작품 네트워크를 분리하여 분석

#### C. 주제분야별 작가 분포 불균형
- **인사이트**: 특정 주제분야(예: 미술사, 미학)에 집중된 작가-연구자 존재
- **의미**: 학술적 관심사가 작가의 장르 선택에 영향을 미칠 수 있음
- **활용**: 주제분야 분포 분석으로 작가의 학술적 관심사 파악

#### D. 발행기관별 작가 집중도
- **인사이트**: 특정 대학/연구기관 출신 작가-연구자가 많을 수 있음
- **의미**: 학술 기관이 작가 네트워크 형성에 중요한 역할
- **활용**: 발행기관 정보로 작가-기관 관계 매핑 강화

#### E. 실제 인용 수와 논문 수의 불일치 (KCI 인용 정보 API)
- **인사이트**: 논문 수가 많아도 인용 수가 적은 작가 존재 (논문 품질 차이)
- **의미**: 논문 수보다 인용 수가 학술 영향력을 더 정확히 측정
- **활용**: H지수, 평균 인용 수로 작가의 논문 품질 측정

#### F. 자기 인용 패턴 분석 (KCI 인용 정보 API)
- **인사이트**: 자기 인용 수가 높은 작가는 독립적 연구보다는 기존 연구 확장에 집중
- **의미**: 자기 인용 비율로 작가의 연구 독립성 측정 가능
- **활용**: 자기 인용 비율 분석으로 작가의 학술 활동 특성 파악

#### G. 비엔날레 참여와 작품 활동의 상관관계 (청주공예비엔날레 API)
- **인사이트**: 비엔날레 참여 횟수가 많은 작가는 제도적 인정을 받은 작가
- **의미**: 비엔날레 참여는 작가의 제도적 권위를 측정하는 지표
- **활용**: 비엔날레 참여 횟수로 작가의 제도적 위치 파악

#### H. 공예 작가와 미술 작가의 구분 (청주공예비엔날레 API)
- **인사이트**: 공예 작가와 미술 작가는 다른 제도적 네트워크에 속할 수 있음
- **의미**: 공예 작가의 경우 별도의 segment_id 필요 가능성
- **활용**: 작가의 기법/재질 정보로 작가 분류 정확도 향상

#### I. 레지던시 참여와 제도적 인정의 상관관계 (MMCA 레지던시작가소식 API)
- **인사이트**: 레지던시 프로그램 참여는 국립현대미술관의 인정을 받은 작가임을 의미
- **의미**: 레지던시 참여는 제도적 지원의 중요한 지표
- **활용**: 레지던시 참여 횟수로 작가의 제도적 인정 정도 측정

#### J. 이름 추출의 한계와 개선 필요성 (MMCA 레지던시작가소식 API)
- **인사이트**: 제목/설명에서 작가 이름을 추출하는 방식은 정확도가 제한적
- **의미**: 작가 이름이 명시되지 않은 경우 매칭 실패 가능
- **활용**: 향후 URL 크롤링 또는 별도 작가명 필드 제공 시 정확도 향상 가능

#### K. 소장작품과 제도적 인정의 상관관계 (MMCA 소장작품 API)
- **인사이트**: 국립현대미술관 소장작품 수는 작가의 제도적 인정을 나타내는 최고 지표
- **의미**: 소장작품 수가 많은 작가는 제도적으로 인정받은 작가
- **활용**: 소장작품 수로 작가의 제도적 위치 파악, 제도 점수 계산에 높은 가중치 적용

#### L. 작가명 명시적 제공의 장점 (MMCA 소장작품 API)
- **인사이트**: creator 필드에 작가명이 명시적으로 제공되어 매칭 정확도가 높음
- **의미**: 이름 추출이 필요 없는 API는 매칭 정확도가 높음
- **활용**: 다른 API와 비교하여 매칭 정확도 차이 분석 가능

## 8. 문제 해결 및 트러블슈팅

### 7.1 공통 문제

**문제**: "등록되지 않은 인증키 입니다"
- **원인**: API 키가 유효하지 않음
- **해결**: 공공데이터포털에서 새로 발급받은 키 사용

**문제**: Rate Limit 오류
- **원인**: 초당 요청 수 초과
- **해결**: `time.sleep()` 값 증가 또는 배치 크기 감소

**문제**: None 값 처리 오류
- **원인**: API 응답에 None 값 포함
- **해결**: `safe_str()` 헬퍼 함수 사용

### 7.2 API별 특이사항

**ARKO 작가 목록 API:**
- 데이터량이 적어 전체 수집 가능 (505명)
- 페이지네이션 간단

**ARKO 미술작품 정보 API:**
- 데이터량이 많아 전체 수집 시 시간 소요 (약 1분)
- 테스트 시 샘플만 수집 권장

**ARKO 예술단체 목록 API:**
- 데이터량이 적어 전체 수집 가능 (94개)
- URL 정규화 필요 (상대 경로 처리)

**ARKO 채용정보 API:**
- 2016년 데이터이므로 현재 시점 활용 제한적
- 향후 최신 데이터 API 연동 필요

**KCI 논문 정보 API:**
- 데이터량이 매우 많아 전체 수집 시 시간 소요 (수십만 개)
- 미술 관련 필터링으로 수집량 감소 (~10,000개)
- 이름 매칭 정확도 향상 필요 (동명이인 문제)

**KCI 인용 정보 서비스 API:**
- 데이터량이 매우 많음 (~1,400,000명)
- 응답 시간이 길 수 있음 (평균 14초)
- Rate Limit: 초당 30회 제한
- XML 형식 응답 처리 필요
- 미술 관련 필터링으로 수집량 감소
- 이름 매칭 정확도 향상 필요 (동명이인 문제)
- 실제 인용 수를 제공하여 기존 추정값 대체 가능 ✅

**청주공예비엔날레 API:**
- 공예 작가 중심 데이터 (도자, 목칠, 섬유, 금속 등)
- 국제 비엔날레 데이터 (국가별 작가 정보 포함)
- 입상 정보 포함 (공모전 수상 작가 식별 가능)
- 비엔날레 참여 정보를 제도 점수 계산에 반영 가능 ✅
- 이름 매칭 정확도 향상 필요 (동명이인 문제)

**MMCA 레지던시작가소식 API:**
- 국립현대미술관 공식 레지던시 작가 소식 데이터
- 작가 이름 추출 필요 (제목/설명에서 파싱)
- 레지던시 참여 정보를 제도 점수 계산에 반영 가능 ✅
- 이름 추출 정확도 향상 필요 (정규표현식 기반)

**MMCA 소장작품 API:**
- 국립현대미술관 공식 소장작품 데이터
- 작가명이 명시적으로 제공됨 (creator 필드)
- 소장작품 정보를 제도 점수 계산에 반영 가능 ✅
- 국립현대미술관 소장은 제도적 인정의 최고 지표
