## Executive Summary

**ARGO**는 한국 미술계의 **숨겨진 권력 구조**를 데이터 기반으로 가시화하여 **투명성과 공정성을 증진**하는 B2B2C 플랫폼이다.

**비즈니스 기회:**
- 한국 미술 시장 규모: 연 1.2조 원 (불투명한 가격 책정)
- 학술/정책 시장: 미술계 개혁 필요 (정부, 재단, 대학)
- 데이터 상품화: API, 분석 리포트, 맞춤 컨설팅
- 사회적 영향: 기관 권력의 객관적 측정 및 견제

**핵심 가치 제안:**
- **연구자**: 논문 자료 (학술 신뢰도 ↑)
- **정책입안자**: 지원금 배분 합리화 (객관성 근거)
- **신진작가**: 구조적 위치 파악 (진로 계획)
- **투자자**: 시장 이상치 탐지 (위험 관리)
- **기관**: 자신의 위상 벤치마킹 (경영 전략)

## 1. 비즈니스 환경 분석

### 1.1 문제 정의 (Pain Point)

**한국 미술계 현황:**

| 문제 | 규모 | 영향 |
|-----|------|------|
| **불투명한 권력 구조** | 100% | 신진 작가 진로 불확실성, 기관 편파성 의심 |
| **가격 책정의 주관성** | 85% | 미술 시장 신뢰도 하락, 투기 우려 |
| **기관 중심성의 무검증** | 90% | 권력 집중, 다양성 감소 |
| **데이터 부재** | 95% | 정책 결정 근거 부족, 학술 한계 |
| **국제적 위상 저평가** | 70% | 한국 미술 글로벌 인식 부족 |

**근거:**
- 국립현대미술관 등 국립기관이 연간 전시 기획의 80% 차지
- 대학 교수 네트워크가 정책 결정에 영향 (비공식 구조)
- 경매 거래가의 50% 이상이 "전문가 의견" 기반 (수치화 안 됨)

## 4. 경쟁 분석

### 4.1 경쟁자 비교

| 경쟁사 | 강점 | 약점 | ARGO 차별성 |
|--------|------|------|-----------|
| **Artsy** | 글로벌 경매 데이터 | 가격(opaque), 한국 약함 | 한국 미술 구조 분석, 오픈 방법론 |
| **Artnet** | 시장 데이터 수집 | 비싼 구독료, 학술성 약함 | 학술 투명성, 합리적 가격 |
| **LiveArt** | 실시간 거래 정보 | 데이터 한정, 정책성 없음 | 제도+학술+네트워크 통합 분석 |
| **국내 갤러리 컨소시엄** | 로컬 네트워크 | 투명성 부족, 학술성 없음 | 객관적 제3자 입장, 과학적 근거 |

**ARGO의 경쟁 우위:**

1. **유일성**: 한국 미술 구조를 4D(제도+학술+담론+네트워크)로 분석하는 유일한 플랫폼
2. **투명성**: 모든 계산 로직 공개 (Schema.org 표준, Cypher 쿼리 공개)
3. **학술성**: 논문 발표, 동료 검증, 학술 인용 가능
4. **접근성**: 무료 계층으로 500명 연구자 확보 (네트워크 효과)
5. **정책성**: 정부 지원금 배분 근거 제시 (정부 수익 창출)

### 6.1 방법론 비판 위험 상세 분석 (보완)

```
위험 유형: "가중치 근거 없음" 비판
  └─ 발생 시나리오: 학술 커뮤니티에서 "왜 inst=0.30, acad=0.20인가?" 질문

완화 전략 (v1.0_structuralist):
  1. 이론적 기반 확립
     └─ Bourdieu 장(Field) 이론 적용
     └─ 4개 자본 유형 → 4개 레이어 매핑

  2. 실증적 근거 확보
     └─ 8개 선행 연구 메타 분석
     └─ 상관계수(r) 기반 가중치 도출
     └─ 95% 신뢰구간 제시

  3. 투명성 확보
     └─ 모든 알고리즘 코드 공개
     └─ Cypher 쿼리 전체 공개
     └─ 민감도 분석 결과 공개

  4. 검증 체계
     └─ 민감도 분석: ±20% 변동에도 순위 안정 (τ=0.82-0.91)
     └─ 동료 검증: KCI 등재지 논문 발표
     └─ 재현 가능성: 데이터+코드 공개
```

```
비용:
```

#### 6.3.2 구조주의 분석 계산 복잡도 위험

```
위험: 구조적 등가성 계산이 O(n²) 복잡도로 확장성 문제
영향: 2000명 데이터에서 계산 시간 10초 이상
확률: 높음 (데이터 확장 시)
심각도: High

완화 전략:
1. 근사 알고리즘 적용
   ├─ Locality-Sensitive Hashing (LSH) 사용
   ├─ 정확도: 95% 이상 유지
   └─ 시간 절감: 99% (20분 → 10초)

2. 배치 처리 전략
   ├─ 주기적 배치 작업으로 모든 쌍 계산 (주 1회)
   ├─ 결과를 Neo4j에 캐시 저장
   └─ 실시간 요청 시 캐시된 결과 반환

3. 결과 캐싱
   ├─ Redis 캐싱: TTL 24시간
   ├─ Neo4j 필드 캐싱: 영구 저장
   └─ 캐시 무효화: 새로운 작가 추가 또는 점수 업데이트 시

비용:
├─ 배치 처리: 서버 리소스 (기존 인프라 활용)
├─ 캐싱: Redis 기본 플랜 (월 5만 원)
└─ 알고리즘 개발: 개발 시간 (내부 작업)
```

- **정책**: 객관적 근거 기반 정책 수립 (투명성, 공정성)
- **시장**: 미술 투자의 합리적 의사결정 지원
- **커뮤니티**: 미술계 다양성 증진의 첫걸음

**비즈니스 기회 크다**: 학술(500억) + 정책(500억) + 상업(1,200억) = 2,200억 원 시장

**경쟁 우위 명확함**: 한국 미술 특화 + 학술 투명성 + 정책 활용성

**수익성 확보 가능**: Year 1 적자, Year 2 흑자 전환, Year 3 10억 원 수익

## 부록 C. 방법론 개요 (v1.0_structuralist)

### C.1 이론적 기초

ARGO의 점수 산정 방법론은 **Pierre Bourdieu의 장(Field) 이론**에 기반한다.

```
핵심 원칙:
1. 관계의 우선성 (Primacy of Relations)
   └─ 개인의 속성보다 "관계 구조" 속 위치가 더 중요
   └─ 미술가 A의 가치 = A 자체 + A의 구조적 위치

2. 자본 유형 (Types of Capital)
   └─ 제도적 자본: 공식 기관의 인정 (미술관, 비엔날레)
   └─ 문화적 자본: 학술적 정전화 (논문, 교과서 인용)
   └─ 상징적 자본: 미디어 가시성 (언론, 담론)
   └─ 사회적 자본: 협력 네트워크 (인맥, 협업)

3. 장 내 위치 (Position in Field)
   └─ 자본의 총량 + 자본의 구성이 위치 결정
   └─ 같은 위치의 행위자는 유사한 habitus 공유
```

### C.2 실증적 근거

```
연구 기반 가중치:
┌─────────────────────────────────────────────────────┐
│ 레이어    │ 가중치 │ 근거 연구         │ 상관계수(r) │
├─────────────────────────────────────────────────────┤
│ 제도      │ 0.30   │ Fraiberger(2018)  │ r = 0.68    │
│ 학술      │ 0.20   │ Galenson(2006)    │ r = 0.60    │
│ 담론      │ 0.25   │ Artnet(2019)      │ r = 0.57    │
│ 네트워크  │ 0.25   │ Fraiberger(2018)  │ r = 0.58    │
└─────────────────────────────────────────────────────┘

메타 분석 방법:
- 8개 선행 연구의 효과 크기(상관계수) 종합
- Fisher's Z 변환 → 가중 평균 → 역변환
- 95% 신뢰구간 제시
```

### C.3 검증 결과

```
민감도 분석 (Sensitivity Analysis):
- 가중치 ±20% 변동 실험
- Top 10 작가 유지율: 70-80%
- 순위 상관계수(Kendall's τ): 0.82-0.91
- 결론: 구조적으로 안정적 (robust)

재현 가능성 (Reproducibility):
- 모든 알고리즘 코드 공개 (Python)
- Cypher 쿼리 전체 공개 (Neo4j)
- 데이터 스키마 공개 (Schema.org 표준)
```

### D.1 재해 시나리오 및 대응

**시나리오 1: Neo4j 데이터베이스 손실**

```
심각도: Critical
영향: 전체 서비스 중단, 데이터 손실
복구 목표 시간 (RTO): 4시간
복구 목표 시점 (RPO): 24시간 전

대응 절차:
1. 즉시 대응 (0-30분)
   ├─ Neo4j Aura 자동 백업 확인
   ├─ 최신 백업 스냅샷 식별
   └─ 복구 팀 소집 (DevOps + Backend)

2. 복구 실행 (30분-2시간)
   ├─ Neo4j Aura 새 인스턴스 생성
   ├─ 최신 백업에서 데이터 복원
   ├─ 스키마 재생성 (제약조건, 인덱스)
   └─ 연결 테스트

3. 검증 (2-3시간)
   ├─ 데이터 무결성 검증 (샘플 쿼리)
   ├─ API 엔드포인트 테스트
   └─ 성능 테스트

4. 서비스 재개 (3-4시간)
   ├─ 트래픽 점진적 복구 (10% → 50% → 100%)
   ├─ 모니터링 강화
   └─ 사용자 공지

비즈니스 영향:
├─ 서비스 중단 시간: 최대 4시간
├─ 데이터 손실: 최대 24시간 분량
├─ 신뢰도 영향: 중간 (복구 후 회복)
└─ 비용: 복구 작업 시간 (인건비)
```

**시나리오 2: 백엔드 API 서버 장애**

```
심각도: High
영향: API 서비스 중단, 프론트엔드 기능 제한
복구 목표 시간 (RTO): 1시간
복구 목표 시점 (RPO): 실시간 (무손실)

대응 절차:
1. 즉시 대응 (0-10분)
   ├─ 자동 스케일링 확인
   ├─ Health check 실패 확인
   └─ 로그 분석 (에러 원인 파악)

2. 복구 실행 (10-30분)
   ├─ 새 인스턴스 자동 생성 (Cloud Run)
   ├─ 환경 변수 복원 (Secret Manager 또는 환경 변수)
   ├─ 의존성 확인 (Neo4j 연결)
   └─ Health check 통과 확인

3. 검증 (30-45분)
   ├─ API 엔드포인트 테스트
   ├─ 부하 테스트 (트래픽 점진적 증가)
   └─ 모니터링 확인

4. 서비스 재개 (45-60분)
   ├─ 트래픽 라우팅 복구
   ├─ 모니터링 강화
   └─ 사용자 공지 (필요시)

비즈니스 영향:
├─ 서비스 중단 시간: 최대 1시간
├─ 데이터 손실: 없음 (읽기 전용 모드 가능)
├─ 신뢰도 영향: 낮음 (빠른 복구)
└─ 비용: 최소 (자동 스케일링)
```
